# Y.YE Portfolio

视觉设计师 / 游戏策划个人作品集基础版本，使用 React + Vite 构建。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 内容替换

- 个人资料、项目、能力和经历：`src/data.js`
- 页面结构：`src/main.jsx`
- 视觉样式：`src/styles.css`
- 首页动态战术地图：`src/main.jsx` 中的 `TacticalField`

姓名、学校、联系方式与经历已根据郭明泽的正式简历更新。当前仍需补充个人头像、项目截图、策划案页面或原型演示素材，再将抽象项目视觉替换为真实案例图。
